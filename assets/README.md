# Figure images — how to swap in real photos

The position images used by [`training-plan.md`](../training-plan.md) live in
`figures3d/` as rendered 3D scenes, two per position:

- `{position}-side.jpg` — side view
- `{position}-high.jpg` — high angle (shows the hands)

**To replace any render with a real photograph:** download a photo, rename it to
the exact filename it replaces, drop it into `figures3d/`, commit. The training
plan picks it up automatically — no document edits needed.

## Where to get free, legal photos

Wikimedia Commons hosts freely licensed photos (every file page shows its
license and author, plus a download button). The pages below carry real photos
of each position. When you use one, note its author and license in the credits
table at the bottom of this file — CC BY and CC BY-SA photos require the
credit; public-domain ones don't, but note them anyway.
