# Curriculum Modules

Fourteen subject areas. Together they cover every part of
[`jujitsu.md`](../../jujitsu.md) — see the
[coverage map](../README.md#coverage-map-every-area-of-the-atlas) for the
part-by-part accounting.

Every module has the same shape, so you can find the same information in the
same place on every page:

| Section | What's in it |
|---|---|
| **Front matter** | Atlas coverage, prerequisites, session count, drill IDs, checkpoint |
| **Why this module exists** | The argument for spending mat time here |
| **What you must own** | The short list. Depth beats breadth. |
| **Lessons** | Numbered, each with content, the game that tests it, and an **Atlas** column pointing at the table it comes from |
| **The drill block** | A ready-made session: warm-up → reps → chain → game → roll, each slot linked to its atlas table |
| **Blending it into a roll** | The tasks that force this material into live sparring |
| **Checkpoint** | Measurable. You either pass it or you don't. |
| **Related** | Sibling modules and the deep technique pages |

## Reading order

**A new student** works 00 → 01 → 02 → 03, and touches 09 twelve minutes at a
time from the first month. Everything else waits.

**A blue belt** who is stuck is usually missing 04 (retention), 10 (scrambles) or
the grip-fighting half of 11 — in that order of likelihood.

**A coach** builds a class from one module's drill block and one concept from 11.
